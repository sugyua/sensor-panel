# Sensor Panel

> Painel de telemetria e monitoramento de hardware em tempo real desenvolvido para monitores secundários dedicados e integração com o ecossistema de ferramentas locais.

## Recursos
- Telemetria de CPU, GPU, VRAM, RAM e temperaturas com atualização suave.
- Layout responsivo para telas dedicadas (incluindo painéis internos de gabinete).
- Modo portátil com scripts PowerShell e versão nativa standalone.
- Integração e inicialização via [Xiri Launcher](https://github.com/sugyua/xiri-launcher).
